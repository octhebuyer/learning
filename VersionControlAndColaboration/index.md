

# Prioridade 1: Controlo de Versões Avançado & Colaboração

A base absoluta. Um expert deve ir muito além dos comandos básicos commit, push e pull.

   - Estratégias de Branching e Fluxos: Dominar Git Flow, GitHub Flow e Trunk-Based Development.
   - Operações Avançadas de Git:
        - Interactive Rebase (git rebase -i): Limpeza de histórico, squash e reordenação de commits.
        - Resolução Complexa de Merge Conflicts: Saber usar ferramentas de three-way merge e entender a estratégia de fusão.
        - Git Cherry-Pick e Git Bisect: Isolar commits específicos para hotfixes e usar pesquisa binária no histórico para detetar onde um bug foi introduzido.
        - Git Reflog e Reset: Recuperação de commits "perdidos" ou branches eliminados acidentalmente.

- Code Review & Pull Requests de Alto Nível: Estruturar PRs pequenos, utilizar PR templates, fazer revisões construtivas e usar Draft PRs.
